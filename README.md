# Plano da Obra

Versão pública, só de leitura, do plano da obra (fases, Gantt, responsáveis, datas e % feita).

**Ver o plano:** https://cclx-pt.github.io/plano-obramoitabarreiro/

O plano é editado no Claude. Esta cópia é atualizada automaticamente de hora a hora,
e só muda quando os dados do plano mudam.

- `index.html` — a página publicada
- `tools/build.py` — gera `index.html` a partir da página do Claude
